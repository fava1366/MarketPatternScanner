ماسح الگوی بازار

اسکن طلا و فارکس با داده Twelve Data · بدون اتصال به حساب MT5 و بدون معامله

منبع داده

API Key را وارد کنید. درخواست داده از طریق اتصال امن HTTPS در Android انجام می‌شود.

کلید فقط روی همین گوشی ذخیره می‌شود؛ آن را در چت ارسال نکنید.

دسترسی به داده یک‌دقیقه‌ای، نمادها و تعداد درخواست‌ها تابع پلن Twelve Data است.

اسکن بازار

API Key را ذخیره کنید و اسکن را بزنید.

نمودار کندلی و محل الگو

پس از دریافت داده واقعی، کندل‌ها و محل الگو نمایش داده می‌شود.

نتیجه تأیید چندتایم‌فریمی

هنوز اسکن انجام نشده است.

قواعد تشخیص

سه کندل بسته‌شده بررسی می‌شوند. بدنه کندل سوم باید کاملاً بالاتر یا پایین‌تر از بدنه اول باشد؛ تماس مرزی نیز رد می‌شود. سیگنال نهایی فقط وقتی صادر می‌شود که آخرین الگوی M3، M5 و M15 هم‌جهت باشد.

این نسخه فقط سیگنال تشخیصی می‌دهد؛ معامله، حدضرر، حدسود یا سود و زیان محاسبه نمی‌کند.
